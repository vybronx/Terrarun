# Terrarun

TERRARUN is an Android-first mobile application that transforms real-world running into a territory capture strategy game using GPS route recording, closed loop detection, and geographic grid evaluation.

> **Status:** Milestone 0 (Project Foundation & Documentation) in progress. Application feature implementation will begin in Milestone 1.
